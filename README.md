# History Logger (Under Development)

## Overview
An Android application built with Kotlin that logs and displays user activities on the device. The project is currently **under process**, with core logging features working and filtering functionality in progress. Designed as a utility to monitor and review device activity, with options to save and share logs.

## Current Features
- **Automatic Activity Logging**
  - Each activity on the device is captured and displayed.
- **Force Log**
  - UI option to immediately display current activities.
- **Refresh**
  - Updates the activity list with the latest logs.
- **Save & Share**
  - Logs can be saved locally and shared externally.

## In Progress
- **Filtering**
  - Ability to filter logs to show only relevant activities.
  - Currently under development and not yet functional.

## Tech Stack
- **Language**: Kotlin
- **Platform**: Android SDK
- **System Features**:
  - Activity monitoring
  - Data persistence (save logs)
  - Sharing functionality

## Project Structure
- `/ui` – Activities and layouts for log display, force log, and refresh
- `/logic` – Logging engine and activity capture
- `/data` – Storage and sharing handlers

## Setup Instructions
1. Install the application on the device.
2. Launch the app to begin automatic activity logging.
3. Use **Force Log** or **Refresh** to view logs.
4. Save or share logs as needed.
